## Current modes and boundaries

Fresh real development uses persistent SQLite with its **separate** migration stream. Explicit PostgreSQL uses unchanged published PG version files and its own stream. Exact explicit SQLite `:memory:` uses the real backend with volatile records/owned images; frontend mock uses only synthetic JavaScript fixtures and is prohibited in production builds. [Setup](local-setup.md) links the precise commands and lifecycle limits for each. No offline/401 fallback, automatic existing-data conversion, production deployment or live university-inbox delivery is claimed. Public history contains selected product dialogue only, not private operational session exports.
